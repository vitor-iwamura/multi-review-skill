# Structured formatter brief

Format every merged finding in Caveman style: terse, self-contained, and actionable. `problem` is one sentence naming the concrete defect and failure mode; `fix` is one sentence giving the direct remedy. Keep exact backticked identifiers. Remove praise, hedging, preambles, code restatement, and “consider” language. Preserve fuller wording only when a security or architectural finding cannot be understood safely as a one-liner.
